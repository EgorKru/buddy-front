# WebSocket Flow - Полное описание работы

## 🔄 Полный Flow работы приложения

### 1. Логин и инициализация

```
Пользователь вводит логин/пароль
    ↓
POST /api/auth/login
    ↓
Получаем { user, token }
    ↓
Сохраняем в localStorage: token, user
    ↓
Перезагружаем страницу (для переподключения WebSocket)
    ↓
StompProvider монтируется и проверяет токен
    ↓
Если токен есть → создается STOMP клиент
    ↓
Подключение к wss://pager.website/ws через SockJS
    ↓
Токен передается в заголовках:
  - Authorization: Bearer <token>
  - X-Authorization: Bearer <token>
    ↓
onConnect вызывается → setConnected(true)
    ↓
Подписка на /user/queue/errors для обработки ошибок
```

### 2. Открытие чата

```
Пользователь открывает /chat/{chatId}
    ↓
useEffect проверяет: chatId && client && connected
    ↓
Если все OK → subscribeToChat()
    ↓
Подписка на /topic/chat/{chatId}
    ↓
Загрузка сообщений через REST API: GET /api/chats/{chatId}/messages
    ↓
Сообщения отображаются в UI
```

### 3. Отправка сообщения

#### Вариант A: WebSocket подключен

```
Пользователь вводит сообщение и нажимает "Отправить"
    ↓
sendMessage() вызывается
    ↓
Оптимистичное обновление: сообщение сразу показывается в UI
    ↓
client.publish({
  destination: '/app/chat.sendMessage',
  body: JSON.stringify({
    chatId: <chatId>,
    content: <текст>,
    type: 'TEXT'
  })
})
    ↓
Бэкенд получает сообщение
    ↓
Бэкенд отправляет всем подписанным на /topic/chat/{chatId}
    ↓
WebSocket получает сообщение через подписку
    ↓
Оптимистичное сообщение заменяется реальным
```

#### Вариант B: WebSocket НЕ подключен

```
Пользователь вводит сообщение и нажимает "Отправить"
    ↓
sendMessage() вызывается
    ↓
Оптимистичное обновление: сообщение сразу показывается в UI
    ↓
chatAPI.sendMessage(chatId, content) через REST API
    ↓
POST /api/chats/{chatId}/messages
    ↓
Бэкенд сохраняет сообщение
    ↓
Оптимистичное сообщение заменяется реальным из ответа API
```

### 4. Получение сообщений

#### Через WebSocket (реальное время)

```
Другой пользователь отправляет сообщение
    ↓
Бэкенд публикует в /topic/chat/{chatId}
    ↓
WebSocket получает сообщение через подписку
    ↓
subscribeToChat() обрабатывает сообщение
    ↓
setMessages(prev => [...prev, messageDto])
    ↓
UI обновляется автоматически
```

#### Через REST API (при загрузке страницы)

```
Пользователь открывает чат
    ↓
loadMessages() вызывается
    ↓
GET /api/chats/{chatId}/messages?page=0&size=50
    ↓
Получаем список сообщений
    ↓
setMessages(response.content.reverse())
    ↓
Сообщения отображаются в UI
```

## 🔧 Технические детали

### WebSocket подключение

**URL:** `wss://pager.website/ws` (конвертируется в `https://pager.website/ws` для SockJS)

**Протокол:** STOMP over SockJS

**Аутентификация:**
- Токен передается в `connectHeaders`:
  ```javascript
  {
    Authorization: `Bearer ${token}`,
    'X-Authorization': `Bearer ${token}`
  }
  ```

**Подписки:**
- `/user/queue/errors` - ошибки WebSocket
- `/user/queue/notifications` - уведомления
- `/user/queue/messages` - уведомления о сообщениях
- `/topic/chat/{chatId}` - сообщения в чате

**Отправка сообщений:**
- Destination: `/app/chat.sendMessage`
- Body: `{ chatId: number, content: string, type: 'TEXT' }`

### Обработка ошибок

1. **Ошибка аутентификации:**
   - Очищается localStorage
   - Редирект на `/login`

2. **Ошибка подключения:**
   - `setConnected(false)`
   - Статус меняется на "Подключение..."
   - Fallback на REST API для отправки сообщений

3. **Ошибка отправки:**
   - Оптимистичное сообщение удаляется
   - Текст возвращается в поле ввода
   - Показывается alert с ошибкой

## 🎨 Отображение сообщений

### Стили

- **Свои сообщения:** Градиентный фон (синий-фиолетовый), белый текст
- **Чужие сообщения:** Белый фон, темный текст (#333)

### Оптимистичное обновление

При отправке сообщения:
1. Создается временное сообщение с `isOptimistic: true`
2. Сообщение сразу показывается в UI
3. При получении реального сообщения через WebSocket - заменяется
4. При ошибке - удаляется

## 🔍 Диагностика

### Проверка подключения

В консоли браузера должны быть логи:
- `✅ STOMP: Connected successfully!`
- `✅ Подписались на чат: <chatId>`

### Проверка токена

```javascript
localStorage.getItem('token') // Должен быть не null
```

### Проверка статуса

В интерфейсе должно быть:
- "Подключено" - если WebSocket работает
- "Подключение..." - если WebSocket не подключен

## ⚠️ Известные проблемы и решения

1. **Бесконечное "Подключение..."**
   - Причина: Ошибка аутентификации WebSocket
   - Решение: Перезагрузить страницу после логина

2. **Сообщения не отправляются**
   - Причина: WebSocket не подключен
   - Решение: Используется fallback через REST API

3. **Сообщения не видны (белые)**
   - Причина: Отсутствует цвет текста в стилях
   - Решение: Добавлен `color: #333` в `.messageText`

4. **Сообщения не приходят в реальном времени**
   - Причина: WebSocket не подключен или подписка не работает
   - Решение: Проверить консоль на ошибки, перезагрузить страницу

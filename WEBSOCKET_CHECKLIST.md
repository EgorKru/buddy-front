# Чеклист проверки WebSocket

## 📋 Что проверить на бэкенде:

### 1. Логи при отправке сообщения

После отправки сообщения в логах бэкенда должны появиться:

```
=== WebSocket: Получено сообщение через /app/chat.sendMessage ===
Request: chatId=2, content=1, type=TEXT
✅ SenderId определен: {userId}
✅ Сообщение создано в БД: messageId={id}, chatId=2
📤 Отправка сообщения в топик: /topic/chat/2
✅ Сообщение отправлено в топик: /topic/chat/2
📤 Отправка подтверждения в: /user/{userId}/queue/message-sent
✅ Подтверждение отправлено в: /user/{userId}/queue/message-sent
```

**Если нет логов "=== WebSocket: Получено сообщение ===":**
- Метод `sendMessage` в `WebSocketChatController` не вызывается
- Проверьте логи "=== STOMP SEND ===" - должна быть команда SEND

**Если нет логов "✅ Сообщение отправлено в топик":**
- Проблема с `convertAndSend` в топик
- Проверьте ошибки в логах

**Если нет логов "✅ Подтверждение отправлено":**
- Проблема с `convertAndSendToUser`
- Проверьте, что `senderId` не null

### 2. Проверка в Network tab (браузер)

1. Откройте DevTools → Network tab
2. Найдите WebSocket соединение (`+websocket`)
3. Кликните на него
4. Откройте вкладку "Messages"
5. Отправьте сообщение
6. Должны появиться STOMP сообщения:
   - `SEND` → отправка сообщения (от фронтенда)
   - `MESSAGE` → подтверждение отправки (от бэкенда в `/user/queue/message-sent`)
   - `MESSAGE` → сообщение в чат (от бэкенда в `/topic/chat/2`)

**Если в Messages нет сообщений от бэкенда:**
- Бэкенд не отправляет сообщения через WebSocket
- Проверьте логи бэкенда на наличие ошибок

## 🔍 Что проверить на фронтенде:

### В консоли браузера должны быть:

1. **При подключении:**
   - `✅ STOMP: Connected successfully!`
   - `✅ STOMP: Subscribed to /user/queue/errors`
   - `✅ useMessageSender: Успешно подписались на подтверждения отправки сообщений`
   - `✅ Успешно подписались на чат: {chatId}`

2. **При отправке сообщения:**
   - `📤 Публикуем сообщение через STOMP: {destination: '/app/chat.sendMessage', ...}`
   - `✅ Сообщение опубликовано через WebSocket, ждем подтверждения`
   - `✅ Добавляем новое оптимистичное сообщение в список`

3. **При получении подтверждения:**
   - `📬 Получено сообщение в /user/queue/message-sent:`
   - `📬 Получено подтверждение отправки: {status: 'sent', ...}`

4. **При получении сообщения:**
   - `📨 Получено сообщение через WebSocket:`
   - `📨 Парсированное сообщение: {id, content, ...}`

## ❌ Если не работает:

### Проблема: Нет подтверждений

**Проверьте на бэкенде:**
- Вызывается ли `convertAndSendToUser` после обработки сообщения?
- Правильно ли определяется `senderId`?
- Отправляется ли подтверждение в путь `/user/{userId}/queue/message-sent`?

**Проверьте на фронтенде:**
- Создана ли подписка на `/user/queue/message-sent`? (должен быть лог `✅ useMessageSender: Успешно подписались`)
- В Network tab → WebSocket → Messages есть ли `MESSAGE` от бэкенда?

### Проблема: Нет сообщений в топик

**Проверьте на бэкенде:**
- Вызывается ли `convertAndSend` после обработки сообщения?
- Правильно ли формируется путь топика: `/topic/chat/{chatId}`?
- Отправляется ли `MessageDto` в правильном формате?

**Проверьте на фронтенде:**
- Создана ли подписка на `/topic/chat/{chatId}`? (должен быть лог `✅ Успешно подписались на чат`)
- В Network tab → WebSocket → Messages есть ли `MESSAGE` от бэкенда в топик?
